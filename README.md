# ระบบบริหารจัดการและติดตาม Action Plan ปีงบประมาณ 2570
**โรงพยาบาลโคกศรีสุพรรณ อำเภอโคกศรีสุพรรณ จังหวัดสกลนคร**

เว็บแอปพลิเคชัน Node.js (Express + Tailwind CSS + Chart.js) สำหรับติดตามแผนปฏิบัติการเพิ่มรายได้ มาตรการลดรายจ่าย สิทธิประโยชน์ PPFS 54 รายการ และศูนย์ติดตามความต้องการรายงาน IT (Dashboard Monitor)

## ความสามารถหลัก
- **Executive Dashboard**: สรุป KPI เป้าหมายรายได้/ลดรายจ่ายทั้งปี เทียบผลงานจริงสะสม พร้อมกราฟแยกตามกลุ่มงานและแนวโน้มรายเดือน (ต.ค. 2569 – ก.ย. 2570)
- **Action Plan Explorer (11 กลุ่มงาน)**: ค้นหา กรองตามกลุ่มงาน/ประเภทแผน คลิกเพื่อดูรายละเอียด KPI, IT Monitor และบันทึกผลงานจริงรายเดือน (พร้อมเพิ่ม/ลบกิจกรรม และ Export CSV)
- **PPFS 54 รายการ**: ตารางรายการสิทธิประโยชน์ PPFS ครบทั้ง 54 รายการ พร้อมรหัส ADP, ช่องทางเบิก (FDH/KTB/NAP/NTIP/43แฟ้ม) และบันทึกเป้าหมาย/ผลงานจริง
- **IT Dashboard Monitor Hub**: ศูนย์รวมรายการรายงานที่แต่ละกลุ่มงานต้องการให้ IT พัฒนา พร้อมติดตามสถานะ (`รอทำ` / `กำลังพัฒนา` / `พร้อมใช้งาน`)
- **Roadmap & วิเคราะห์สถานการณ์**: PDCA Roadmap งาน ER, แผน 30/60/90 วัน งาน IPD และวิเคราะห์สถานการณ์งานผู้ป่วยใน (ภาคผนวก ก.)

## การติดตั้งและรันระบบ
```bash
npm install
PORT=3540 npm start
```
ค่าเริ่มต้นรหัสผ่านโหมดแก้ไข: `ksp2570` (กำหนดผ่าน Environment Variable `EDIT_PIN` ได้)
